# Spec: qa-playwright-1223-pin

## Goal
Fix the broken QA smoke gate — pin `playwright`/`@playwright/test` to the version
whose bundled Chromium build (1223) matches the browsers actually installed on the
VPS, so `nightshift/bin/qa-smoke.mjs` can launch a browser again and every cycle can
pass QA. This is a P0 `[bug]`: the last ~50 unattended cycles all FAILed because the
smoke gate crashed at browser launch.

## Root cause (verified this cycle)
- `qa-smoke.mjs` does `import { chromium } from 'playwright'` → resolves to
  `/app/node_modules/playwright` (currently `1.61.1`), which demands Chromium build
  **1228** (`playwright-core/browsers.json`).
- The VPS browser cache `/ms-playwright` only contains build **1223** (installed
  2026-07-02) and is **root-owned + read-only** for the `night` user — so `npx
  playwright install` cannot add 1228 there (confirmed: `Permission denied`).
- Result: `browserType.launch: Executable doesn't exist at
  /ms-playwright/chromium_headless_shell-1228/...` → smoke exits non-zero → no cycle
  can merge. `playwright-core@1.60.0` bundles Chromium **1223** (verified by
  inspecting the npm tarball's `browsers.json`).

## Scope
- `package.json` — pin `"playwright": "1.60.0"` and `"@playwright/test": "1.60.0"`
  (exact, no caret) so npm resolves a single `playwright-core@1.60.0` → build 1223.
- `package-lock.json` — regenerated by `npm install` to lock 1.60.0.
- `/app/node_modules` — downgraded in place by `npm install` (persists on the VPS for
  future cycles; node_modules isn't reinstalled between cycles).
- No app source, no schema, no `nightshift/` harness file touched.

## Acceptance criteria
- `node_modules/playwright-core` reports version `1.60.0` after install.
- `node nightshift/bin/qa-smoke.mjs --slug qa-playwright-1223-pin /partnerships`
  launches a browser and exits **0** (HTTP 200, no app-console errors, no horizontal
  overflow at 1280 + 375) — i.e. the gate that has been failing now passes.
- `npx next build` still passes (typecheck included) — the downgrade doesn't break the
  app build.
- `git diff` touches only `package.json` + `package-lock.json`.

## Out of scope
- The `partnerships-map-list-sync` WIP (preserved on its own branch; a future cycle
  QAs + lands it now that the gate works).
- Any change to `/ms-playwright`, `PLAYWRIGHT_BROWSERS_PATH`, or the harness env
  (root-owned / outside my control — flagged for the human in the CHANGELOG).
- Upgrading browsers to 1228 (would need root; pinning down is the reversible,
  in-repo fix).
